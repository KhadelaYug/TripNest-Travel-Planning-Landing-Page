# TripNest – Travel Planning Landing Page 🌍

## 📌 Project Overview

**TripNest** is a modern and responsive landing page UI/UX design for a fictional travel planning service created using **Figma**. The platform helps users discover popular destinations, organize their travel plans, estimate budgets, and explore exciting travel experiences.

This project is developed as an individual assignment for the **IPS UI/UX Design using Figma** subject.

## 🎯 Objectives

- Design a visually appealing and user-friendly landing page.
- Apply Figma Auto Layout for consistent spacing and alignment.
- Create reusable UI components.
- Maintain consistent colors, typography, and design styles.
- Design responsive layouts for desktop and mobile screens.
- Understand fundamental UI/UX design principles.

## 👥 Target Audience

- College students and young professionals.
- Families planning holidays.
- Travel enthusiasts and adventure seekers.
- Users who want to organize trips and manage travel budgets.

## ✨ Key Features

- **Header and Navigation:** Brand logo, navigation links, and call-to-action button.
- **Hero Section:** Attractive travel imagery, introductory text, and trip-planning actions.
- **Popular Destinations:** Destination cards featuring Bali, Manali, Paris, and Dubai.
- **Feature Cards:** Smart Trip Planner, Budget Estimator, and Discover Hidden Gems.
- **How It Works:** A simple three-step travel planning process.
- **Testimonials:** Sample traveler reviews and ratings.
- **Call-to-Action Section:** Encourages users to start planning their next adventure.
- **Footer:** Quick links, contact information, and social media links.

## 🛠️ Tools and Technologies

- **Figma** – UI/UX design and prototyping.
- **Auto Layout** – Flexible layouts and consistent spacing.
- **Reusable Components** – Buttons, destination cards, feature cards, and testimonial cards.
- **Color and Typography Styles** – Consistent visual design.
- **Responsive Design** – Desktop and mobile layouts.

## 🎨 Design System

### Color Palette

| Color | Hex Code | Usage |
|---|---|---|
| Sky Blue | `#2563EB` | Primary buttons and highlights |
| Turquoise | `#14B8A6` | Secondary accents |
| Light Gray | `#F8FAFC` | Background |
| Dark Navy | `#0F172A` | Headings and body text |
| Coral | `#FF7F50` | Accent elements |
| White | `#FFFFFF` | Cards and content backgrounds |

### Typography

- **Poppins:** Headings and section titles.
- **Inter:** Body text, descriptions, and labels.

## 🧩 Reusable Components

The design includes reusable components such as:

1. Navigation Button
2. Primary and Secondary CTA Buttons
3. Destination Card
4. Feature Card
5. Testimonial Card

These components help maintain consistency and make future design updates easier.

## 📱 Responsive Design

The landing page is designed for two screen sizes:

- **Desktop:** 1440 px width.
- **Mobile:** 390 px width.

The mobile layout adapts the navigation, hero section, search panel, and content cards for smaller screens.

## 📖 Design Explanation

TripNest uses a clean layout, travel photography, readable typography, and a blue-and-turquoise color palette to create a welcoming travel experience. Clear call-to-action buttons help users understand the main actions, while destination cards make travel options easy to explore.

Auto Layout and reusable components improve design consistency and help the layout adapt to different screen sizes.
